You were right that these tools exist. There are 51 `circuit_` tools. `?` marks an optional parameter, and the tools with no parameters say "none".

## Circuit editing

| Tool | Parameters |
|---|---|
| `circuit_set_circuit` | `nodes` (array), `edges` (array), `runSim?` (boolean, default true) |
| `circuit_set_nodes` | `nodes` (array) |
| `circuit_set_edges` | `edges` (array) |
| `circuit_update_component` | `id` (string), `updates` (object; `data` is merged, not replaced) |
| `circuit_delete_component` | `id` (string or array of strings) |
| `circuit_define_mcu` | `nodeId` (string), `presetKey?` (string), `pins?` (array), `geometry?` (object), `code?` (string), `label?` (string) |
| `circuit_validate_circuit` | `nodes?` (array), `edges?` (array) |
| `circuit_set_note_cards` | `noteCards` (array of `{id, markdown, minimized, x, y}`) |

The schemas list many optional parameters as nullable. The `anyOf [type, null]` pattern just means you can omit them or pass null.
